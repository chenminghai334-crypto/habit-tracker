# 习惯打卡

一个零依赖、纯本机的习惯打卡网页应用（PWA）。自己添加要长期坚持的习惯，设好每天的提醒时间，到点提醒你，做完点一下打钩。

- **最快上手**：双击 `index.html`，浏览器直接打开就能用（打卡、统计、备份、导出日历）
- **想要到点弹系统通知 / 离线使用**：双击 `启动.cmd`，浏览器打开 `http://localhost:8080/`
- **手机上装成 App**：见 [部署说明.md](部署说明.md)
- **详细用法**：见 [使用说明.md](使用说明.md)

功能一览：自定义习惯（图标 / 目标数量 / 多个每日提醒时间）· 一键打卡与计数打卡 · 连续天数与完成率统计 · 到点页面内提醒（通知 + 提示音 + 震动）与稍后提醒 · 一键导出 `.ics` 导入手机日历，锁屏也能提醒 · JSON 备份与恢复 · 浅色/深色主题 · 离线可用。

数据只保存在你自己的浏览器里，不上传、不注册。

## 开发者

```bat
node serve.js                        :: 本地起服务，默认 8080
node --test test/logic.test.mjs      :: 跑纯逻辑单元测试
node tools/make-icons.mjs            :: 重新生成 PNG 图标（用内置 zlib，无依赖）
```

结构：`logic.js`（纯逻辑，浏览器与 Node 测试共用）、`app.js`（界面与交互）、`sw.js` + `manifest.webmanifest`（PWA 离线与安装）、`icons/`、`serve.js`（零依赖静态服务器）。

> `logic.js` / `app.js` 故意写成普通脚本而不是 ES 模块：这样双击 `index.html` 用 `file://` 打开时不会被浏览器的 CORS 拦住，也就不必为了日常打卡去起本地服务。`logic.js` 的接口挂在 `window.HabitLogic` 上，单元测试用 `new Function` 载入同一份源码。
